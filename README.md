# Until Labs design reference

A saved copy (via saveweb2zip) of the Until Labs website, untillabs.com. It's kept here only as a visual and layout reference for the RefillGuard project.

**Not affiliated with Until Labs.** All text, images, logos and fonts in this repo belong to their respective owners. Nothing here is an original work of this repo's owner.

## Contents

- `index.html`, `index_1.html`: the saved pages
- `css/`, `js/`: compiled styles and scripts
- `images/`, `fonts/`: page assets

To view it, open `index.html` in a browser.
